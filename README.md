# 低价投标质量预警

识别制造业低价竞争背后的交付与质量风险。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块统一加载这些资料，并校验领域标识、版本、参与方、事实和约束等必要字段。

当前资料反映以下领域事实：

- 监管将综合运用标准引领、价格执法和质量监管整治内卷式竞争
- 政策希望企业把资源用于提质增效而非低价内耗
- 经营主体发展质量需要与竞争秩序共同治理

## 风险研判模型

`src/assessment.py` 在共享资料之上实现一次完整的低价投标研判,对应 `fixtures/assessment.json` 与 `contracts/assessment.schema.json`:

- **候选解释而非单一分数**:对每位触发预警的投标人并行列示效率优势、短期促销、不可持续压价、交付偷换材料、关联企业协同等解释,各自给出支撑、反证和尚缺证据,系统不下定性结论。
- **多源一次研判**:招标规则、报价版本、可验证成本项、产能、历史交付、检验、投诉、关联/联合投标,以及价格执法和质量监管线索统一归并为事实。
- **报价版本与乱序事件**:新报价通过 `supersedes` 取代旧版本,旧依据保留在修订历史;事实按接收时间(无则按发生时间)纳入,迟到的价格异动、监管事件只影响后续版本。
- **商业秘密授权**:`clearance` 分为 public/internal/trade_secret,研判时按查看人密级放行,范围外只计数提示存在,不披露内容。
- **豁免与复核队列**:人工豁免到期后投标人自动回到复核队列,到期原因进入复核理由。
- **交付后校正**:授标后的进场检验结果作为 `delivery_feedback` 增量事实,强化或削弱此前疑点;每次研判生成不可变修订版本,依据可回溯。

运行测试:

```
python -m unittest discover -s tests
```

## 本地校验

运行项目自带测试可确认样例资料符合约定。仓库不保存账号、密钥、连接串或真实身份资料。
